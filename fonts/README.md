# Fonts

`Web437_IBM_VGA_8x16.woff` is the IBM VGA 8x16 face from
[The Ultimate Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/)
v2.2 by VileR, in its `Web437` cut, which carries the CP437 character set and
nothing more.
