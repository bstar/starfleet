STAR/FLEET is a family of programs that live in the terminal: a music player, a Discord client and a file manager, all built on the same foundation crate, all drawn with the same docked panels and the same sixteen themes. They are written in Rust on ratatui, run on Linux and macOS, work over SSH, and take the keyboard or the mouse as you prefer.

Nothing phones home. There are no accounts, no telemetry and no subscription. Each program is a single binary and a directory of its own files.

╡ STAR/AMP ╞

A terminal player for a more civilised age.

No streaming. No radio stations. No account required. Winamp inspired. It plays the files on your disk, and it plays all of them.

FEATURES

  • FLAC, MP3, Vorbis, AAC and ALAC natively; APE, WavPack, Musepack, DSD, Opus and WMA through libavcodec. Bit-perfect, at the file's own rate.
  • CUE sheets as first-class citizens. Gapless albums. Crossfade.
  • An SQLite index: 34,000 files scanned in under eight minutes cold, a second warm.
  • Docked Winamp-style panels, sixteen themes, classic .wsz skin import, a seven-mode visualizer, album art as real pixels.
  • Local listening history, with optional Last.fm and ListenBrainz scrobbling and Discord presence.
  • A parametric EQ that reads and writes Equalizer APO files. ReplayGain.
  • A smart-playlist query language, library timelines, and a queue that plays a library over one SSH connection.
  • Every open terminal is the same player. MPRIS and a control socket.

╡ STAR/CORD ╞

A terminal client for Discord that feels like Winamp.

Real-time chat with your friends and servers. The account, the servers and the settings stay in Discord's own app; this is a way to sit in the conversation from a terminal.

FEATURES

  • A live gateway session: messages, edits, deletions, typing, presence and read marks, resumed when the connection drops.
  • Servers, channels, DMs and threads, with folding categories, unread and mention counts, mutes and a lazy member list.
  • Pictures in the terminal: attachments, avatars, custom emoji and animated GIFs as real pixels in kitty, WezTerm, Ghostty and foot; half-blocks anywhere else.
  • :name: completion, reactions, a GIF picker, and attachments by path or clipboard paste.
  • A bell, a status line and, if you like, a desktop notification.
  • Search across a channel or a whole server.
  • One column of modules and the same sixteen themes as STAR/AMP.

It does not do voice, video, screen sharing, server administration, account settings or friend requests.

╡ STAR/FOLD ╞[ UNRELEASED ]

Unfold your filesystem.

┌─ STAR/FOLD ───────────────────────┐
│ ~ » projects » star                │
│ ────────────────────────────────── │
│   staramp/                    dir  │
│ * starcord/                   dir  │
│ * starfold/                   dir  │
│   starkit/                    dir  │
│   notes.md                    2.1k │
│ ┌ preview ────────────────────────┐│
│ │ # STAR/FOLD                     ││
│ └─────────────────────────────────┘│
│ marks 2 · queue 2 ops · run: r     │
└────────────────────────────────────┘

A file manager where the directories you drill through stack up behind you, the files you mark stay marked wherever you go, and nothing is copied, moved or deleted until you run the queue.

FEATURES

  • The fold stack: each directory pushes a level, the levels behind you fold to one line each, and alt+up/down walks them.
  • Persistent marks that follow you across directories; y and m copy or move whatever is marked to where you stand.
  • An operations queue. Nothing touches the disk until you say so, and delete goes to the trash.
  • A preview panel for text, real-pixel images, directory summaries and a hexdump.
  • One column, the same sixteen themes, and the mouse everywhere.
  • Linux and macOS.

GET IT

No tag yet; that command builds main. The packaging (AppImage, .deb, Arch, tarball, home-manager) is in place for the first release. It has been built and tested headlessly so far and the window has not yet run in a real terminal, which status is honest about. The repository.

╡ STAR/KIT ╞

The terminal-UI crate that STAR/AMP, STAR/CORD and STAR/FOLD share. All three wanted the same theme engine, the same picture rendering, the same docked panels and the same idea of where a program's files live, and copying the answer between them would have meant maintaining three of everything.

WHAT IS IN IT

  • Themes: TOML with a base16 block and a role table, sixteen built in, a derivation chain, Stylix and COSMIC detection, and .wsz import.
  • Pictures through ratatui-image: kitty, iTerm2, sixel, half-blocks.
  • Layout: a dockable panel tree, a virtualised list, wrapping, a text input.
  • Panel chrome: the double-bordered frame, scrollbar, overlay and confirm.
  • The dull necessities: the app directory, file logging, atomic writes, terminal setup and the panic hook, a keybinding table and a help view.

This is not a general TUI framework. Its API is what the three programs needed, and it grows when one of them needs more.

USE IT

starkit = { git = "https://github.com/bstar/starkit", tag = "v0.2.1" }

Versions are 0.x and tagged; each application pins a tag. The tag above is the newest one pushed. The repository and its docs.
